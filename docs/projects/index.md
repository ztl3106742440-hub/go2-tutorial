## 系统工程：巡检与综合门户

系统把 Web/API 网关、任务管理、运动仲裁、视觉采集识别及进程健康管理串联起来；综合门户提供动作、VLM、目标跟随、语音和巡检入口。研究重点是模块接入、状态反馈、配置部署和现场故障定位。

部分模块已有历史实机或离线验证记录；移动端真实控制、统一运动仲裁完善、多视角计数、完整三维自主导航不能一概视为完成。没有机器人时，可先从公开 SDK 的 Mock 示例了解感知—决策—动作链路。

## 如何复现与了解贡献

每个代码仓库首页提供 `git clone`、安装与运行步骤。上游算法、机器人模型与 SDK 均归其作者所有；本组项目主要展示系统集成、适配、实验与调试工作。具体完成状态以带日期的验证记录为准。
